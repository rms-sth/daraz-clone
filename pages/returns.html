How to Return

Follow the steps below to initiate a return request.

Return Steps

  1. Login to your account and go to My Orders.
  2. Select the order and click “Request Return”.
  3. Choose a reason and submit the request.
  4. Package the item securely for pickup.

Conditions for Returns

  • Product must be unused and unworn.
  • Include original tags, manual, and warranty card.
  • Return within 7-14 days depending on product category.
  • Original packaging must be intact.
